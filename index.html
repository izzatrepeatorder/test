How to read this dashboard
Target (10.0%) — the project goal from the repeat order audit. Every cohort should move toward this.
Baseline (Nov 2025: 7.0%) — permanent anchor. First full cohort before any campaigns. Never changes.
Latest (Feb 2026 (to 28th): 8.1%) — most recent month where full 90 days have passed. When positive, campaigns are working. When negative, we're below where we started.

For deep-dive data (branch analysis, individual customer list, time-to-repeat), see the Excel workbook.
